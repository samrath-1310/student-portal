# Student Portal
A C++ based student portal developed as part of the Git laboratory activity.

## Project Purpose
The project demonstrates the development and version control of a student portal using C++ and Git.

## Development Environment
- Windows
- Visual Studio Code
- C++
- Git
- GitHub

## Features
The student portal will provide functionality for managing student information and accessing different portal services.
Planned features include:
- Student authentication
- Student profile management
- Academic dashboard
- Account settings
- Student information management
